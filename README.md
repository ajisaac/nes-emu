# Nintendo Emulator

A NES emulator translated from https://github.com/fogleman/nes

The plan is to take the base NES emulator from above and translate it from Go to C++. 
I'll use this as a base for further development.

I want to make a completely cycle accurate emulator with multithreading, a debugger,
a complete set of mappers, support for game genie and other accessories, possibly 
networked multiplayer, etc.

## Plan

- [ ] Translate code from Go to C++
- [ ] Create a UI in QT
- [ ] Debugging capabilites
- [ ] All mappers 
- [ ] Multithreading
- [ ] Cycle accurate
- [ ] Networked multiplayer
- [ ] Accessories
